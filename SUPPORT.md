# Support / 获取支持

## Questions and troubleshooting / 使用问题与排障

Search the documentation and existing GitHub issues first. If the problem remains, open a GitHub issue with the Zentrola version or commit, deployment method, operating system, expected behavior, actual behavior, and sanitized logs.

请先检索文档和已有 GitHub Issue。问题仍未解决时，请提交 Issue，并注明 Zentrola 版本或 commit、部署方式、操作系统、预期行为、实际行为以及脱敏后的日志。

The community does not currently provide a guaranteed response SLA or commercial support. Please do not send credentials, Virtual Keys, JWTs, cookies, database URLs, prompts, model responses, or personal data.

社区目前不承诺响应 SLA，也不提供默认商业支持。请勿提交 Credential、Virtual Key、JWT、Cookie、数据库地址、prompt、模型响应或个人信息。

## Security / 安全问题

Do not open a public issue for vulnerabilities. Follow [SECURITY.md](SECURITY.md) or [SECURITY.zh-CN.md](SECURITY.zh-CN.md).

漏洞不得通过公开 Issue 报告，请遵循 [SECURITY.md](SECURITY.md) 或 [SECURITY.zh-CN.md](SECURITY.zh-CN.md)。
