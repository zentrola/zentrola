# Zentrola documentation

[English](README.md) | [简体中文](README.zh-CN.md)

This directory contains user-facing documentation for installing, configuring, and operating Zentrola. Internal implementation notes belong in `../dev-docs` and are not part of the published documentation.

## Start here

- [Getting Started](getting-started.md): install a release bundle, configure dependencies, and create the first administrator.
- [Client configuration](client-configuration.md): connect Codex, Claude Code, or another compatible client.
- [Deployment and operations](operations.md): run processes, check health, back up data, and configure logs.
- [Environment variables](../.env.example): complete configuration template and defaults.
