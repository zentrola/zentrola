# 阶段 6：最小 Admin Web

2026-09-06 在现有仓库 `web/` 完成管理界面，与 Go API 联调通过。实现 Vue 3 + TypeScript + Vite，前后端共用仓库；生产页面由 Go 直接提供，延续 `app + postgres` 部署结构。

## 页面与操作

| 页面 | 支持操作 |
| --- | --- |
| 登录与初始化 | 空系统设置首位管理员，已有账号认证、失效重新登录、退出 |
| 成员 | 列表、创建、启停、Key 列表、签发、设置过期时间、撤销 |
| 分组 | 列表、创建、成员分配和移除、模型授权和撤销 |
| 模型 | 查看目录、启停、查看和维护分组授权 |
| 资源 | 查看、创建、凭证录入和覆盖、连接测试、启停 |
| 用量记录 | 按成员、模型、资源和时间组合筛选、分页、请求及 Attempt 详情 |
| 操作日志 | 列表、操作结果、对象及 requestId 详情 |

界面使用真实 API，区分加载、空数据、错误和操作中状态。成员和资源列表支持搜索已加载记录；所有列表可继续加载分页，关联候选项遍历全部分页。长业务 ID 使用字符串，页面不会转换为 JavaScript Number。

成员列表的“密钥”列通过 `limit=1` 查询最新签发的一条密钥。点击旁边的查看图标，在弹层中按最新在前的顺序分页查看该成员的密钥，展示显示名称、脱敏密钥和过期日期；完整密钥仍仅在签发时展示一次。分配密钥的到期日期仅选择年月日，按浏览器本地时区的当天 23:59:59.999 转为 UTC 提交，可选择今天，不选则长期有效；列表和查看弹层的过期日期也仅显示年月日。

撤销入口位于密钥弹层的“操作”列，仅对启用、未过期且未撤销的密钥展示。确认后撤销指定密钥，成功时移除该行操作，保留分页位置和其余记录；成员主列表不展示撤销操作。

## 凭证与权限

管理员 JWT 与后端到期时间保存在同源 localStorage（`zentrola.admin.session`），刷新或重新打开页面时先通过 `/me` 校验再恢复身份，沿用后端 8 小时有效期。退出、到期和 401 响应会清理存储、身份及在途请求，并同步同源标签页；恢复时临时网络错误允许重试，不删除有效凭证。浏览器禁用存储时降级为当前页面会话。密码、上游凭证和业务数据不写入浏览器存储，JWT 不进入 URL 或日志。前端不设置默认管理员密码，空系统先 [初始化首位管理员](首次管理员初始化.md)，已有系统使用原账号。

上游 Credential 通过密码输入框提交，保存或关闭后清除输入，不回显已有值。Virtual Key 创建后用独立弹窗只展示一次，支持复制及“我已保存”确认；关闭后仅保留元数据。停用、移除和撤销操作有确认弹窗，执行期间禁止重复提交。

权限仍由后端每次复核；页面隐藏或禁用按钮只是交互提示。连接测试区分 HTTP 请求成功与 `data.ok=false` 的业务失败，显示结果码和耗时，不把 HTTP 200 一律显示为通过。测试不会自动启用资源。

## 用量与国际化

用量列表展示 `clientProtocol`、输入、输出、缓存命中、耗时和状态。缺失 Token 显示“—”，0 显示 0；详情区分本地拒绝和真实上游 Attempt，不伪造使用量或成本。组合筛选使用固定起止时间及游标，日期发送为 RFC3339，界面按浏览器本地时区显示。查询最多 366 天，默认最近 24 小时；重新选择最近范围可点击“重置”。写入队列显示当前进程的待写与失败数，不当成历史用量汇总。

UI 文案集中在 `src/i18n.ts`，状态仍使用 `ACTIVE / DISABLED / REVOKED / SUCCESS` 等英文编码。当前仅中文词条，未添加完整英文翻译。协议名、模型编码、操作事件码及 ID 保留原值。

## 运行方式

开发模式：后端默认 8080，`web` 目录执行 `npm.cmd ci`、`npm.cmd run dev`，访问 `http://127.0.0.1:5173`。Vite 代理 `/api`，不扩大后端 CORS 范围。

生产模式：执行 `npm.cmd run build` 后从根目录启动 Go，访问后端根地址；Docker 构建自动包含页面。仅公开构建目录中的入口、favicon 和 assets，API、Gateway、Swagger 保持原有路由行为。构建静态页面不会把后端配置打包进浏览器。

完整命令和前端目录说明见 [web/README](../web/README.md)。
